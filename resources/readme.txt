　稽古 · 二十四史情境检索（绿色免安装版）
═══════════════════════════════════════════════

【本版修复了什么】

  上一版在你电脑上显示 ERR_FILE_NOT_FOUND（找不到 index.html）。
  原因已定位并彻底修掉：

  · 真正的原因有两层：
      1) 界面文件此前靠"从 exe 里释放到磁盘、再让浏览器按路径去读"，
         一旦写入被安全软件拦截或路径不同，页面就找不到文件；
      2) 更底层的问题——资源读取用了 ResourceManager.GetStream，
         而资源是以 Byte[] 写入的，取出来永远是 null，
         于是内存里其实一个界面文件都没有。

  · 现在怎么改的：
      把 HTML / CSS / JS / 规则表 / 201 条史书数据全部转成 base64 字符串，
      **直接编译进 exe**；程序启动时在内存里建索引，
      浏览器发出的每一个请求都由程序在内存中直接应答。
      ——不再释放文件、不再拼路径、不再做资源查找。
      所以磁盘上有没有这些文件，都已经不影响界面显示。

  · 可用程序自带的命令行参数自证（可选）：
      稽古.exe --selfcheck 报告.txt
      报告里应为：RESULT: ALL ASSETS RESOLVE FROM MEMORY (0 fails)


【你要做的只有两步】

  第一步：双击「稽古-安装包.exe」（如果用的是绿色版，就跳过这步，
　　　　　直接解压 稽古-portable.zip）。

  第二步：一路点「下一步 / 开始安装 / 完成」，然后在桌面上双击
　　　　　「稽古」图标即可运行。

  安装程序会：
    · 把程序装到 C:\Users\<你的名字>\AppData\Local\Programs\稽古
      （每用户目录，不需要管理员权限，不会弹权限提示）
    · 在桌面创建「稽古」快捷方式（带专属图标）
    · 在开始菜单创建「稽古」
    · 在「设置 → 应用」里登记，可随时正常卸载

  想换安装位置：向导第一页可以改，或点「浏览…」选择。


【如果双击没反应，按顺序试这三招】

  1) 安装包：右键「稽古-安装包.exe」→「以管理员身份运行」。
     绿色版：右键「稽古.exe」→「以管理员身份运行」。

  2) 安全软件误拦：某些杀毒软件会拦住刚下载的 exe（因为它是新文件、
     没有数字签名）。把「稽古」整个文件夹加入白名单，或临时关闭杀毒软件
     的「实时防护」再双击；程序本身不联网、不写系统目录，是安全的。

  3) 缺少显示组件：程序会自己检测。如果提示缺少
     「Microsoft Edge WebView2 Runtime」，点「是」会自动帮你下载安装
     （约 2MB，需要联网一两分钟），装完再运行即可。
     Windows 10 / 11 一般自带这个组件。

  程序不会静默闪退：无论缺少什么，都会弹出一个中文提示告诉你原因。


【怎么用】

  1. 在输入框里写下令你困扰的现实处境，越具体越好
     （人物关系、时间压力、你已经做了什么）。
  2. 点「稽古一问」。
  3. 程序在本机检索 201 则史事（先秦到清），给出最相似的三条历史事件，
     每条包含五个部分：
        原文摘录 · 现代文翻译 · 核心人物 · 关键决策 · 最终结果
  4. 下面「鉴」的部分，是依据内置规则模板生成的分析、要避免的做法、
     可行动作。
  5. 点「看看引擎如何理解这句话」，可以看到本机是怎么分词、怎么扩展
     同义词、怎么给稀有词加权的。


【联网说明】

  所有检索、分析、建议都在你的电脑上完成，不调用任何 AI 接口。
  唯一会联网的动作是：启动时静默检查一次数据版本，只下载发生变化的
  史书文件。连不上网时自动用本地数据，不会弹错误提示。


【自检】

  打开「藏书阁 → 关于与自检 → 运行自检」，
  顶部状态栏会显示「自检 全部通过」，并列出测试用例命中的史事。
  如果显示异常，把那句话反馈给开发者即可。


【文件说明】

  Microsoft.Web.WebView2.Core.dll   界面渲染内核（随包附带，无需另外安装）
  Microsoft.Web.WebView2.WinForms.dll
  WebView2Loader.dll                内核加载器（随包附带）
  data\                             史书数据（200 则史事）
  data_base.txt                     数据更新源地址（可自行修改）
  使用说明.txt                       本文件


【换成完整版数据】

  把符合格式的 JSON 放进数据目录（「藏书阁」页会显示完整路径），
  重启程序自动导入。格式示例：

  {
    "book": "史记",
    "items": [
      {
        "chapter": "项羽本纪",
        "title": "陈平反间，范增去楚",
        "original": "……",
        "translation": "……",
        "figures": ["项羽", "范增"],
        "decision": "……",
        "outcome": "……",
        "themes": ["将帅不和"]
      }
    ]
  }
